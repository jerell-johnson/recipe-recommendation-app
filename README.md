# Recipe Recommendation App

A Python desktop application that recommends recipes based on a user's selected ingredients and dietary preferences.

## About the Project

I developed this project to practise my Python programming skills and create an application that helps users find suitable recipes based on the ingredients available to them.

The application uses recipe data stored in a JSON file and compares the user's selections with available recipes to provide relevant recommendations.

## Features

- Recommends recipes based on selected ingredients
- Supports dietary preferences
- Calculates ingredient match percentages
- Uses a graphical user interface (GUI)
- Loads recipe information from JSON data
- Handles user input and errors

## Technologies Used

- Python
- Tkinter
- JSON

## Project Files

- `recipe_recommender.py` — Final version of the application
- `rec2.json` — Recipe data used by the application
- `prototype_v2.py` — Earlier development version

## How to Run

1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Keep `recipe_recommender.py` and `rec2.json` in the same folder.
4. Run:

python recipe_recommender.py

## Development

This project was developed through multiple prototypes. `prototype_v2.py` represents an earlier stage of development, while `recipe_recommender.py` is the final version.
